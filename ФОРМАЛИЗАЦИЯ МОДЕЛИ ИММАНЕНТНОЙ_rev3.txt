ФОРМАЛИЗАЦИЯ МОДЕЛИ ИММАНЕНТНОЙ ТОПОЛОГИЧЕСКОЙ ЭМЕРДЖЕНТНОСТИ
Технический документ (редакция на основе рекомендаций § 6)

0. СТАТУС ДОКУМЕНТА

Это не философский текст и не готовая симуляция. Это спецификация дискретной динамической системы, достаточная для программирования и проверки. Философская рамка задаёт структуру; данный документ фиксирует параметры, которые рамка недоопределяла, и явно помечает то, что остаётся свободным (для поиска в симуляции) или принципиально неформализуемым.

Что фиксировано: мера сложности C, мера потребности need, правило актуализации, статус C_cont, определение квалиа.
Что остаётся свободным: численные значения Φ_crit, C_cont, параметры распределения бюджета — они либо находятся в симуляции, либо являются предметом выбора.
Что не формализуется: Void, вопрос «кто провёл cross()», переживаемость квалиа.

1. БАЗОВЫЕ ОБЪЕКТЫ

1.1. Граф

Направленный мультиграф G = (V, E):
- V — конечное множество вершин;
- E — конечное мультимножество направленных рёбер e = (u, v), u, v ∈ V;
- каждому ребру приписан вес φ(e) ∈ ℝ_{≥0} — потенциал фрустрации;
- вес вершины φ(v) = Σ_{e ∋ v} φ(e) — суммарная инцидентная фрустрация.

Граф не вложен в метрическое пространство. Метрика (геодезическая) определяется позже, через пассивированную подложку (§ 4.3).

1.2. Кликовый комплекс

Для графа G определим кликовый комплекс K(G):
- 0-симплексы — вершины V;
- 1-симплексы — рёбра E (без учёта кратности и направления для топологии);
- k-симплексы (k ≥ 2) — (k+1)-клики в G (полные подграфы на k+1 вершинах).

K(G) — симплициальный комплекс. Его топологические инварианты (числа Бетти β_k) — основа меры сложности.

Замечание. Направленность рёбер важна для динамики (§ 3), но не для топологии. Топология использует носитель графа (неориентированный граф с кратностями, сведёнными к 1).

1.3. Числа Бетти

β_k = rk H_k(K(G); ℚ) — ранги групп гомологий над ℚ. Вычислимы стандартными алгоритмами (приведённая матрица границ).

Для графов (1-мерных комплексов) β_0 = число компонент связности, β_1 = цикломатическое число |E| − |V| + β_0. Для кликовых комплексов высшие β_k учитывают «пустоты» (треугольные циклы, заполненные 2-симплексами, дают β_2 и т.д.).

2. МЕРА СЛОЖНОСТИ C(G)

2.1. Определение

C(G) = dim K(G) + |E| − |V| + β_0(G) + 1

где:
- dim K(G) = max{ k : существует k-симплекс в K(G) } — размерность кликового комплекса (= размер наибольшей клики минус 1);
- |E| − |V| + β_0(G) — цикломатическое число графа μ(G) (число независимых циклов);
- +1 — нормировка, гарантирующая C > 0 для нетривиальных графов.

2.2. Свойства (проверяемые)

- Целочисленность: C(G) ∈ ℤ_{>0}. Это ключевое для Теста 3 (квантование).
- Монотонность при эскалации: добавление вершины с рёбрами к подграфу увеличивает C. Проверено на уровнях: отрезок C = 2, треугольник C = 4, тетраэдр C = 7, K5 C = 11.
- Различение уровней: C строго возрастает на каждом качественном уровне.
- Вычислимость: dim K(G) — поиск максимальной клики (NP-труд в общем случае, но для малых графов симуляции — приемлемо); μ(G) — линейно; β_0 — линейно.

2.3. Почему именно так

- dim K(G) различает качественные уровни (отрезок → треугольник → тетраэдр → K5).
- μ(G) различает количество циклов внутри уровня (масштабирование).
- β_0 учитывает связность (важно для распределённых структур).
- Целочисленность обеспечивает квантование без введения дополнительных дискретных величин.

Альтернативы (для сравнения в симуляции): C = Σ k·β_k; C = β_0 + β_1 + dim. Они дают другие численные значения, но сохраняют монотонность и целочисленность. Выбор фиксирован, но не единственен.

3. ДИНАМИКА: ОПЕРАТОР T_cross

3.1. Схема оператора

T_cross(G_t) = Apply_R1( Select_R2(G_t), G_t )

Оператор детерминирован при фиксированном G_t и фиксированных параметрах. Система не имеет доступа к T_cross как к функции (архитектурное разделение, § 3.5); она имеет доступ только к M (измерение) и N (определение шага).

3.2. Правило 2: выбор главного противоречия

Select_R2(G) = argmax_{G_sub ⊆ G} C(G_sub)

где максимум берётся по всем связным подграфам G_sub, содержащим хотя бы одно ребро с φ > 0.

Tie-breaking: лексикографический порядок по отсортированному списку вершин (детерминизм). Если максимум достигается на нескольких подграфах, выбирается лексикографически наименьший.

Порог: если max C(G_sub) < C_min (где C_min — минимальная сложность, при которой возможна перестройка; для отрезка C_min = 2), оператор не применяется — система в равновесии. В модели с безысходностью это невозможно, но формально порог нужен для завершения симуляции.

3.3. Правило 1: вынос конфликта наружу

Apply_R1(G_sub, G) → G'

Шаги:
1. Создать новую вершину v_new ∉ V.
2. Для каждой вершины v_i ∈ G_sub создать ребро (v_new, v_i).
3. Веса новых рёбер:
   φ_new(v_new, v_i) = F(G_sub) · deg_{G_sub}(v_i) / (2 |E_sub|)
   где F(G_sub) = Σ_{e ∈ G_sub} φ(e), deg_{G_sub}(v_i) — степень v_i в G_sub. Это сохраняет суммарную фрустрацию: Σ_i φ_new = F(G_sub).
4. Пассивировать старые рёбра: φ(e) → 0 для всех e ∈ G_sub.
5. Направление новых рёбер: (v_new → v_i) — от новой вершины к старой (новая вершина «владеет» разрешением).

Замечание. Направление выбрано так, чтобы новая вершина была арбитром, а старые — подчинёнными. Это согласуется с диалектическим «снятием»: старое удерживается как момент нового.

3.4. Полный шаг

G_{t+1} = Apply_R1( Select_R2(G_t), G_t )

Если Select_R2 возвращает ∅ (нет подграфа с C ≥ C_min), G_{t+1} = G_t (равновесие).

3.5. Архитектурное разделение

В симуляции определяются две функции:
- step(G) → G' — полный оператор, доступен симулятору;
- observe(G) → (M(G), N(G)) — измерение и определение шага, доступно системе.

Система не вызывает step; она вызывает observe и действует на основе результата. Это реализует тезис «система не может вычислить следующее состояние»: step существует, но недоступен системе.

4. БЮДЖЕТ, ПОТРЕБНОСТЬ, ДИССИПАЦИЯ

4.1. Бюджетное уравнение

На каждом такте t:
E_abs(t) = E_main(t) + E_inter(t) + E_diss(t)

- E_abs(t) — актуализированный бюджет (суммарная фрустрация активных рёбер): E_abs = Σ_{e: φ(e)>0} φ(e).
- E_main(t) — бюджет, идущий на основной шаг (перестройку).
- E_inter(t) — бюджет, идущий на посредников (измерение и предсказание).
- E_diss(t) — диссипация (необратимые потери).

Ограничение: E_rel(t) < E_abs(t), где E_rel = E_main + E_inter — полезно использованный бюджет. Диссипация E_diss = E_abs − E_rel > 0 всегда.

4.2. Распределение по потребностям

need(G_sub) = F(G_sub) = Σ_{e ∈ G_sub} φ(e)

Бюджет распределяется пропорционально потребностям:
E_main(G_sub) = E_main · need(G_sub) / Σ_{G_sub'} need(G_sub')

Прихоть формально не существует: любое «кажущееся произвольным» распределение на макроуровне является сложной потребностью на микроуровне (агрегацией локальных need). В симуляции это проверяется: если распределение не пропорционально need, значит, need определена неверно (или агрегация неточна).

4.3. Пассивированная подложка и метрика

V_pass = { v ∈ V : φ(v) = 0 }
E_pass = { e ∈ E : φ(e) = 0 }

Геодезическая метрика:
d(i, j) = длина кратчайшего пути из i в j по E_pass

Если путь не существует, d(i, j) = ∞ (разные компоненты).

4.4. Диссипация и случайность

Randomness(t) = E_diss(t) / E_abs(t) = 1 − E_rel(t)/E_abs(t)

Свойства:
- Randomness ∈ (0, 1) всегда (диссипация положительна, но меньше полного бюджета);
- убывает с ростом эффективности посредников (E_inter/E_abs → 0 при идеальном предсказании);
- не достигает нуля (посредник всегда тратит часть на себя).

Проверяемое предсказание: Randomness(t) убывает с ростом C(G_t), но асимптотически стремится к Randomness_∞ > 0.

5. КВАЛИА КАК РЕФЛЕКСИВНОЕ ЗАМЫКАНИЕ

5.1. Оператор самоописания

Для подграфа G_sub определим оператор самоописания:
Desc(G_sub) = подграф K(G_sub), порождённый всеми кликами, содержащими v ∈ G_sub

Desc сопоставляет подграфу его кликовую структуру — то, как подграф «видит» себя в топологическом смысле.

5.2. Квалиа как неподвижная точка

Qualia(G) = { G_sub ⊆ G : Desc(G_sub) ≅ G_sub }

Квалиа — подграфы, инвариантные относительно самоописания (с точностью до изоморфизма кликовых комплексов). Это рефлексивное замыкание: подграф, который описывает себя и совпадает с этим описанием.

Свойства:
- Квалиа — не единственный подграф; их может быть несколько (разные «модальности» опыта).
- Квалиа зависят от кластера: разные G дают разные неподвижные точки.
- Квалиа возникают только на континуальном пределе: для малых C неподвижных точек нет (или они тривиальны — одна вершина).

5.3. Порог квалиа

Qualia(G) ≠ ∅  ⇔  C(G) > C_cont

C_cont — свободный параметр, который ищется в симуляции как минимальная сложность, при которой появляются нетривиальные неподвижные точки Desc. Это предсказание, а не подгонка: если C_cont не находится (квалиа возникают при любом C или ни при каком), модель неверна.

6. ПРЕДЕЛЬНЫЙ ПЕРЕХОД К ГЛАДКОМУ ОПИСАНИЮ

6.1. Последовательность графов

Рассмотрим последовательность G_n с C(G_n) → ∞ и фиксированным правилом роста (например, G_{n+1} = T_cross(G_n)).

6.2. Сходимость

Гладкий предел существует, если последовательность G_n сходится в метрике графовых пределов (cut-метрика или spectral-метрика) к некоторому предельному объекту (графону или непрерывному пространству).

Формально: G_n → X в cut-метрике, если для всех функций f: V_n → [0,1] выполняется:
lim_{n→∞} (1/|V_n|^2) Σ_{u,v} f(u) f(v) A_n(u,v) = ∫∫ f(x) f(y) dμ_X(x,y)
где A_n — матрица смежности, μ_X — предельная мера.

6.3. Гладкое описание

Если предел X — гладкое многообразие (или графон с непрерывной плотностью), то динамика T_cross в пределе описывается дифференциальными уравнениями (или интегро-дифференциальными, для графонов).

«Несоответствие» гладкого описания — сигнал, что G_n не сходится к гладкому пределу. Тогда решение ищи уровнем ниже (в дискретной топологии).

6.4. Проверяемость

Симуляция должна показать:
- при C < C_cont — гладкое описание не работает (отклонения велики);
- при C > C_cont — гладкое описание работает (отклонения убывают с ростом C).

Это проверяемое предсказание: C_cont — порог, который находится, а не задаётся.

7. КРИТЕРИИ ПРОВЕРКИ (ТЕСТЫ)

Тест 1: Эмерджентная размерность
Что проверяется: фрактальная размерность пассивированной подложки.
Метод: для G_n с C(G_n) → ∞ вычислить размерность Хаусдорфа–Безиковича (или асимптотическую размерность роста объёма) метрического пространства (V_pass, d).
Критерий: размерность стабилизируется на d = 3 (или d = 3+1 с учётом времени) при n → ∞.
Статус: предсказание. Если размерность не стабилизируется или стабилизируется на другом значении — модель неверна.

Тест 2: Причинная структура без метрики
Что проверяется: появление световых конусов (причинных цепочек) статистически, без введения метрики Минковского.
Метод: для направленного графа G вычислить достижимость: u ≺ v, если существует направленный путь из u в v. Построить «конусы» как множества достижимых вершин. Сравнить статистику с ожидаемой для причинной структуры (например, число пар с u ≺ v как функция «расстояния»).
Критерий: статистика достижимости соответствует причинной структуре с конечной скоростью распространения (без априорной метрики).
Статус: предсказание. Если причинность не появляется — модель неверна.

Тест 3: Квантование архивов
Что проверяется: дискретность значений C и φ(v) на устойчивых структурах.
Метод: после N шагов симуляции собрать распределение C(G_sub) для всех подграфов. Проверить, что оно сосредоточено на дискретных значениях (а не непрерывно).
Критерий: распределение C имеет вид Σ p_k δ(C − C_k), где C_k — целые числа, а p_k — вероятности. Это доказывает топологическую природу квантования.
Статус: следует из целочисленности C (свойство 2.2). Если C определена иначе (не целочисленно), тест может не пройти.

Тест 4: Неубывание сложности
Что проверяется: невозможность обратного хода.
Метод: ввести оператор «стирания» Erase(G, e): удалить ребро e (или вершину). Применить Erase на любом шаге и проверить, что C(G') ≥ C(G) (сложность не убывает) и |V'| ≥ |V| (число вершин не убывает).
Критерий: C и |V| не убывают при любой последовательности Erase. Это подтверждает необратимость.
Статус: следует из определения C (добавление рёбер увеличивает C, удаление — не уменьшает, если вершины остаются). Если C определена иначе, тест может не пройти.

Тест 5: Порог гладкого предела
Что проверяется: существование C_cont, при котором гладкое описание становится применимым.
Метод: для последовательности G_n вычислить отклонение гладкого приближения (например, разность между дискретной динамикой и её континуальным пределом). Построить зависимость отклонения от C(G_n).
Критерий: существует C_cont, при котором отклонение резко убывает (фазовый переход к гладкому режиму).
Статус: предсказание. C_cont находится в симуляции, а не задаётся.

Тест 6: Квалиа как неподвижная точка
Что проверяется: существование нетривиальных неподвижных точек Desc(G_sub) ≅ G_sub при C > C_cont.
Метод: для G с различными C вычислить множество Qualia(G). Проверить, что при C < C_cont оно пусто (или тривиально), при C > C_cont — непусто.
Критерий: Qualia(G) ≠ ∅ ⇔ C(G) > C_cont.
Статус: предсказание. Если C_cont не существует (квалиа везде или нигде), модель неверна.

Тест 7: Распределение по потребностям
Что проверяется: пропорциональность распределения бюджета потребностям.
Метод: на каждом такте вычислить need(G_sub) для всех подграфов и сравнить с фактическим распределением E_main(G_sub).
Критерий: отклонение от пропорциональности убывает с ростом C (на макроуровне распределение точнее).
Статус: следует из определения (4.2), но проверяет корректность реализации.

Тест 8: Асимптотика случайности
Что проверяется: убывание Randomness с ростом C, но не до нуля.
Метод: вычислить Randomness(t) для длинной симуляции. Построить зависимость от C(G_t).
Критерий: Randomness → Randomness_∞ > 0 при C → ∞.
Статус: предсказание. Если Randomness → 0, модель неверна (диссипация не учтена).

8. СВОБОДНЫЕ ПАРАМЕТРЫ И ПРЕДСКАЗАНИЯ

8.1. Свободные параметры (выбор)

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| C_min | 2 | Минимальная сложность отрезка |
| Φ_crit | — | Свободен; порог перестройки, ищется в симуляции или задаётся |
| C_cont | — | Свободен; порог гладкого предела, ищется в симуляции |
| E_inter/E_abs | — | Свободен; доля бюджета на посредников, параметр модели |

8.2. Предсказания (проверяемые)

| Предсказание | Тест | Критерий |
|--------------|------|----------|
| Размерность d = 3 | 1 | Стабилизация на d = 3 |
| Причинные конусы | 2 | Статистика достижимости соответствует причинной структуре |
| Квантование C | 3 | Распределение сосредоточено на целых значениях |
| Неубывание C | 4 | C не убывает при Erase |
| Порог C_cont | 5 | Резкое убывание отклонения при C > C_cont |
| Квалиа при C > C_cont | 6 | Qualia ≠ ∅ ⇔ C > C_cont |
| Распределение по потребностям | 7 | Отклонение убывает с ростом C |
| Randomness → Randomness_∞ > 0 | 8 | Асимптотика положительна |

8.3. Что не предсказывается

- Конкретные значения Φ_crit, C_cont, E_inter/E_abs — они либо параметры, либо находятся в симуляции.
- Конкретные значения физических констант (α, отношения масс) — модель не выводит их напрямую; она выводит структуру (квантование, размерность), а не численные значения.
- Переживаемость квалиа — модель описывает структуру (неподвижную точку), а не феноменологию.

9. ЧТО НЕ ФОРМАЛИЗУЕТСЯ (ГРАНИЦЫ)

9.1. Void
Void — пред-формален. Он не объект, не множество, не пространство. Формализация начинается с cross(). Void — условие начала, а не его элемент. Попытка формализовать Void сделала бы его объектом, что противоречит его определению.

9.2. Вопрос «кто провёл cross()»
Вопрос за границей модели. cross() — аксиома, а не теорема. Формализация не может его обосновать, потому что он — условие формализации. Это очерченная граница, а не слабость.

9.3. Переживаемость квалиа
Модель определяет квалиа как неподвижную точку Desc. Она не объясняет, почему эта неподвижная точка переживается. Это — «трудная проблема», и модель её не решает. Она решает структурную проблему (какие подграфы являются квалиа), а не феноменологическую (почему они ощущаются).

9.4. Творческая актуализация
Правило актуализации (§ 3.3) детерминировано: v_new и его рёбра выводятся из G_sub. Если настаивать, что v_new — действительно новое (не выводимое), то T_cross не функция, и формализация невозможна в строгом смысле. Данный документ выбирает детерминированный вариант, сохраняя генеративный детерминизм и архитектурное разделение (§ 3.5).

10. АЛГОРИТМ (ПСЕВДОКОД)

def step(G):
    # 1. Выбор главного противоречия
    subgraphs = connected_subgraphs_with_positive_phi(G)
    if not subgraphs:
        return G  # равновесие
    G_sub = max(subgraphs, key=lambda s: (C(s), lex_key(s)))
    if C(G_sub) < C_min:
        return G
    
    # 2. Вынос наверх
    v_new = new_vertex()
    F = sum(phi(e) for e in G_sub.edges)
    E_sub = len(G_sub.edges)
    for v_i in G_sub.vertices:
        w = F * deg(G_sub, v_i) / (2 * E_sub)
        add_edge(v_new, v_i, weight=w)
    
    # 3. Пассивация
    for e in G_sub.edges:
        set_phi(e, 0)
    
    return G

def observe(G):
    # Доступно системе (не симулятору)
    M = measure_complexity(G)  # C(G) и локальные C(G_sub)
    N = determine_next_step(G, M)  # выбор подграфа и шага
    return M, N

def simulate(G0, N_steps):
    G = G0
    history = []
    for t in range(N_steps):
        M, N = observe(G)
        G = step(G)  # симулятор имеет доступ к step
        history.append((G, M, N, C(G)))
    return history

Ключевое: observe не вызывает step. Система действует на основе M и N, но не знает G_{t+1}. Это архитектурное разделение реализует онтологическую слепоту.

11. ИТОГ

Документ задаёт конкретную дискретную динамическую систему с:
- топологической мерой сложности C (целочисленной, монотонной);
- детерминированным оператором T_cross (выбор + актуализация);
- бюджетным уравнением с диссипацией;
- рефлексивным определением квалиа (неподвижная точка);
- предельным переходом к гладкому описанию (через графовые пределы);
- восемью проверяемыми тестами.

Что фиксировано: структура, оператор, мера сложности, определение квалиа.
Что свободно: Φ_crit, C_cont, доля бюджета на посредников — параметры, которые либо находятся в симуляции, либо выбираются.
Что не формализуется: Void, вопрос о cross(), переживаемость квалиа — границы, очерченные сознательно.

Это не «окончательная теория». Это спецификация, достаточная для того, чтобы запустить симуляцию и проверить предсказания. Если симуляция даёт d = 3, квантование C, причинные конусы и порог C_cont — модель работает в своих границах. Если нет — модель опровергнута в своих границах, и это нормально для научной гипотезы.
